# 手机与桌面 API 联调契约（v0.4.1）

入口为 `https://ericcself.top`，业务请求使用 `Authorization: Bearer <token>`。令牌通过本机私有配置或平台安全存储提供，不嵌入公开源码、URL 或日志。当前服务个人使用，不存在账户注册、多用户权限或自动交易功能。

| 使用场景 | 路径 | 客户端应处理的字段/边界 |
| --- | --- | --- |
| 能力与运行版本 | `/v1/capabilities`、`/v1/deployment-status` | 是否实现、实际来源、云端版本；不能仅依据客户端版本判断可用性 |
| 目录与搜索 | `/v1/instruments` | `total/items/snapshot_id`，支持 `market/kind/search/limit/offset` |
| K 线 | `/v1/bars/{instrument_id}` | `items` 日期升序；显式 `start/end/limit`，区分不复权价格、成交量单位和历史缺失 |
| 完整性 | `/v1/coverage`、`/v1/cn/history-coverage` | 配置池、全目录历史初始化分别统计；sample 不等于全市场 |
| 全目录快照 | `/v1/cn/quotes` | 有效快照、独立停牌证据和未知缺失分别处理；不是历史日线完整性证明 |
| 板块及龙虎榜 | `/v1/cn/rankings`、`/v1/cn/lhb`、`/v1/cn/lhb/{symbol}/seats` | 交易日、排名口径、单日/多日披露不能直接混加 |
| 美国市场 | `/v1/us/sectors`、`/v1/us/ai` | 行业 ETF 为板块代理，AI 为配置观察池；按各自交易日展示 |
| 可选数据 | 个股资金、事件、经济事实接口 | 先检查 capabilities；有实现不等于已采到生产数据 |

业务状态码约定：

| 状态码 | 客户端处理 |
| --- | --- |
| 200 | 按日期、scope、coverage/task_status 展示；空数组不自动解释为“今日没有行情/披露” |
| 401 | 提示令牌缺失或无效，不自动循环重试 |
| 404 | 标的/路径不存在 |
| 409 | 分页快照不存在或超期，丢弃当前扫描并从 offset=0 重读 |
| 422 | 参数错误，修正参数后再请求 |
| 429 | 请求限流；退避后重试，勿立即并发重发 |
| 501 | 当前能力或经核验数据源不可用；展示原因 |
| 503 | 采集失败、库存数据校验失败或数据库忙；有 Retry-After 时按其等待 |

目录及成员分页从第一页取得 `snapshot_id`，后续页携带同一标识及完全一致的查询条件；30 分钟无活动后超期。全目录快照接口目前不提供该租约，宜查询已经完成并稳定的明确交易日，检查每页 total 和重复代码。

`/healthz` 只说明 API 进程可响应。采集 worker 被用户暂停时，`/readyz` 可返回 503；健康详情中的数据陈旧和服务不可响应应分别显示。日线 GET 在历史不足时可能登记历史请求，但不会自行发起上游抓取，暂停中的 worker 不执行这些请求。

所有市场日期为 ISO 日期；带时区时间保留原偏移。A 股与美股不强制采用同一交易日期。初次联调以明确的最近已验证交易日取数，不能把旧数据标成今天。

浏览器采用同源入口；跨域部署前需要将**实际前端来源**加入 cors_origins。当前默认没有开放任意 CORS。原生移动端和 Python 客户端使用相同鉴权头和业务契约。

调用示例：[Python](../examples/api_client.py)、[JavaScript](../examples/api-client.mjs)。Python 示例从 `MARKET_API_TOKEN` 及可选的 `MARKET_API_BASE_URL` 读取配置；JavaScript 示例不存储令牌，交由调用方管理。两者设置 20 秒超时，错误对象保留状态码及可选的 Retry-After；示例不会自动无限重试。

截至 2026-10-15，已验收日期为 **2026-10-14**，国内配置池 112 个序列、美股配置池 24 个序列。开发时可先使用该日期测试；数据不会因为请求发生在新日期就自动更新。巡检、自动采集及补采仍按用户要求暂停。

公网 `/docs` 和 `/openapi.json` 返回 404；接口结构使用仓库 `docs/openapi.json`，或通过 SSH 隧道查看服务文档。手机蜂窝网络的健康访问由用户实机确认；带鉴权核心请求另由公网验收脚本核对。
