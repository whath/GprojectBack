# 后端扩容、同源日线补齐和异地备份

## 已实施的能力

- 新增 `/v1/cn/quotes?kind=stock|etf&trade_date=YYYY-MM-DD&limit=500&offset=0`：按完整 AKShare 目录、每批 100 代码采集腾讯收盘快照。检查源时间必须属于目标日、北京时间不早于 15:00，验证 OHLC；旧日期、零价、错误上下界均不计有效行情。成交量单位尚未完成逐品类验证，明确标注 `source_unit_unverified`，成交额暂为 null。
- 快照独立存储，不覆盖已有历史日线。`expected` 为目录数，`total` 为有效快照数；独立停复牌报告确认的整日停牌单列 `suspended`；`missing_count` 表示仍无法解释的缺失。暂停几分钟、前日停牌/当日复牌不按整日停牌处理。
- 同花顺年度历史文件若滞后，从同一同花顺板块的近期 `last.js` 文件补齐。必须存在重叠交易日、重叠 OHLC 差异不超过 0.001；不切换板块分类、不覆盖原历史。半导体和人工智能真实样本已验证当天补齐。来源不可访问/冲突时保留原序列，缺失日仍 pending。
- 新浪 ETF 历史文件缺少当天时，核验同源收盘快照的日期及时间，并要求其昨收与已存上一市场交易日收盘一致，才补入当日日线。510300、513100 两个真实样本已通过；无法核验时继续 pending。
- 新增 `/v1/cn/history-coverage` 和 `/v1/tasks?market=CN&scope=full_history`：独立全目录历史补采队列，每轮最多启动 120 秒工作，单请求 45 秒、一次请求、每标的最多 3 次且间隔至少一小时。未处理项优先；定时采集优先、固定窗口前五分钟暂停启动后台补采。运行限北京时间 15:10 后，沿用原采集规则；`has_history` 不代表每个历史交易日完整。
- `/v1/overview` 新增收盘快照和全目录历史进度；原 `/v1/coverage` 仍是配置池口径，不能拿它替代全市场验收。
- 配置池仍为 90 行业、15 概念、5 股票、2 ETF；全目录股票/ETF 扩容使用独立快照及低优先级历史队列。新增配置 `cn_full_close_quotes`、`cn_history_backfill`、`offsite_backup_expected`。

## 同花顺成分限制

同花顺行业/概念页及成分分页本次直接探测均返回 HTTP 200 但正文为 0 字节，无法核验完整页数和成分数量。当前锁定版本 AKShare 没有可靠的完整同花顺成分接口；不能用旧文档中的函数名或东方财富分类替代。保持 `unsupported_membership`，不发布部分成分为完整名单。探测记录：`data/deploy/ths-membership-probe.json`。后续仍需要可验证、允许访问的同花顺完整来源或同花顺原始导出文件。

## 自动异地备份及巡检

用户选择当前电脑作为第二份备份目的地。`scripts/pull_cloud_backup.py` 通过已有 SSH 配置创建 SQLite 在线一致备份，下载至 `data/offsite-backups`，先比较源端 SHA-256 和大小，再复制到临时目录进行 SQLite 恢复/完整性检查及表计数。成功后原子发布、保留最近 30 份，回写云端 `offsite-backup.json`。

`/v1/health` 提供 `offsite_backup`；超过 30 小时未验证会产生后台告警。已创建本聊天自动任务“行情后端巡检与本机异地备份”（id: `automation`），每小时巡检，距最近验证超过八小时才下载新备份。正常或重复已知状态不通知，新故障/恢复/明显补齐才通知。

**本机备份和巡检依赖电脑在线、Codex 保持运行及 SSH 可连接。云端采集/重试和服务器内每日备份不依赖本机。** 本机备份为数据恢复用途，不含服务器 API 密钥或 SSH 私钥；应用代码保存在本工作区，部署配置的机密部分需另行安全管理。
