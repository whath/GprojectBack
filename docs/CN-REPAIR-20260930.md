## 复现和后续运行

在项目根目录 PowerShell 中执行；历史手动采集也需要北京时间 15:10 以后：

```powershell
$env:DATA_DIR='D:/workSpace/Gproject/data/cn-repair-20260930'
$env:CONFIG_PATH='D:/workSpace/Gproject/data/cn-repair-20260930/config.json'
./.venv/Scripts/python.exe -m scripts.collect_acceptance --market CN --date 2026-09-29
./.venv/Scripts/python.exe -m scripts.collect_acceptance --market CN --date 2026-09-30
./.venv/Scripts/python.exe -m scripts.verify_acceptance
```

`verify_acceptance` 是本次 9 月 30 日验收脚本，带本次样本和日期的断言，不是通用生产监控。后续源站状态变化时应按实际任务重新审计结果。

API 使用同一 `DATA_DIR` 和 `CONFIG_PATH`；配置至少 32 字符随机 `API_TOKEN` 后运行 `python -m uvicorn marketdata.api:app --host 127.0.0.1 --port 8000`。本轮临时 HTTP 测试进程已退出，未启动常驻 worker 或云端服务。

调度仍为国内交易日 15:10、17:10、19:10。下一轮先补采当天样本、检查日期及披露，再按配置扩大范围。不要直接将本次样本通过写成全市场通过。
