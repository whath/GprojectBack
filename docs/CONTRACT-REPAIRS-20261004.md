## AKShare 数据源交叉核验

2026-10-04 安装版本及 PyPI 最新版本均为 1.19.1。该版本没有可调用的 `stock_board_cons_ths`、`stock_board_industry_cons_ths`、`stock_board_concept_cons_ths`；同花顺板块信息接口不等于全量成分接口。

实网 `stock_fund_flow_industry` 返回 90 行即时行业数据，金额单位为亿元且有舍入，响应没有交易日期，不能满足同日归属、逐日序列和严格净额容差。东方财富的板块历史资金不能挂到 THS ID 上。未接入这些不合格替代源。

`stock_news_em` 每个关键词本次返回 10 条，原文链接及发布时间可验证。市场由后台配置映射，摘要取源内容片段。更新时间跟随真实内容时间/修订，不以每次抓取时间刷新旧新闻。没有具备全部原文、发布时间、修订/取消证据的计划日历源，因此不把新闻接口声称为完整全球事件服务。原文与商业使用授权仍需部署方核对。

本轮实网证据见 [AKShare 交叉验收](AKSHARE-CROSSCHECK-20261004.json)。`stock_individual_fund_flow` 的原 requests 传输失败后，使用固定版本 `curl_cffi==0.16.3` 在一次性子进程中传输同一 AKShare 请求，URL、参数、解析、供应商及主力定义均不变。000001、600519、688981、920779 各返回 120 个有效交易日，最新为 2026-09-30，真实数据经严格校验后由资金 API 返回 200。此前探测失败的 JSON 保留为历史证据，并非当前不可用结论。

交易所四类目录实采并发布校验通过：沪市主板 A 股 1702、科创板 618、深市 A 股 2904、北交所 348，共 5572 个当期上市标的。沪市退市源 159 行经排除 B 股与处理重复公司后，确认 146 个 A 股代码；深市退市源确认 208 个。`/v1/catalog-coverage` 独立对照四份目录与实际可见标的，本轮缺失和未核验额外标的均为 0。该验收使用临时库，不代表生产库已经全量发布或历史已采满。

收盘快照、停复牌和美股新代码解析已改为调用 AKShare 函数。移除了运行路径中的直接行情抓取及 THS/Sina 原生 HTTP 补充；原始解析函数仅用于旧记录兼容测试。收盘快照来自供应商带交易日期的日线，明确标注市场收盘时间的语义，不冒充实时行情时间戳；每批最多 5 个标的、单轮预算 120 秒，因此全量速度与覆盖仍须云端验收。停复牌源若仅有日期，盘中暂停与复牌当天不视作全天停牌。

`news_economic_baidu` 实网返回 2026-10-05 的 47 条经济事实，新增 `/v1/economic-calendar?trade_date=2026-10-05`，独立轮转采集未来 3 日。保留地区、源时钟、数值、重要性和修订；不凭抓取时间编造发布时间、逐事件原文、数值单位或未经确认的时区。相应字段为 null，限制随响应返回，数据不自动注入 `/v1/events`。来源未变时保持内容版本时间，仅更新单独的核验时间。
