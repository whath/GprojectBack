## 运行控制

- `personal-market-worker.service` 已 active/ enabled，由 systemd 开机启动及异常重启；单个 worker OS 锁和采集锁约束写入。
- 生产 `automatic_collection / automatic_backfill / automatic_refresh_enabled=true`。开发模板保持关闭，拉取仓库不会自动在另一台电脑启动采集。
- 单个来源失败后20分钟重试，最多额外3次；不同来源独立排队。批次预算用尽而仍有未处理标的时继续下一片，不消耗来源失败次数。
- 每片最多120个标的、2个工作线程、90秒请求启动预算；每个子任务有180秒进程期限，超时结束进程组并保留已提交数据。固定窗口前5分钟停止启动新片。
- worker 保持1000MiB内存上限，CPU配额100%（一核）、Nice10；低于1GiB空闲磁盘时暂停新采集并告警。
- 新队列表 `automation_jobs` 保存进度及重试时间；异常重启恢复未完成任务，并限制连续中断次数。截断的批次日志尾部另存后恢复，不忽略中间损坏。
- `/v1/health` 增加 `automation` 队列摘要；后台告警继续提供失败状态。`/readyz` 只表示运行就绪，不能证明市场数据已全部补齐。
- 自动电脑备份、独立巡检自动化继续关闭，`automatic_backup=false`、`offsite_backup_expected=false`；未创建本机常驻任务。

## 验收

224项后端测试通过，0失败、0跳过，含真实 worker 入口、时间窗口、停牌/节假日、重试限额、恢复、磁盘保护及分批日期一致性。修复了旧 worker 入口局部导入遮蔽 `CollectorLock`、旧调度忽略备份关闭开关的问题。股票概览日期单独取股票日线，避免更早更新的板块或ETF错误推进个股榜单日期。

在服务器独立SQLite副本上执行18类真实采集场景。目录、美股、停牌、经济日历、宏观、分级新闻、东方财富行情/资金/成分、同花顺、指数、资金、估值均采入；股票、ETF、分时各执行两批4个标的，两批均有实际成功数据且待采数减少，证明续采会前进。龙虎榜席位因批次预算续跑；BLS仍返回HTTP错误，保留已标明来源的有限窗口补充，未称为完全修复。

启用前保留SQLite一致性快照和代码/配置回退点；第一次启动校验暴露入口错误时已自动回退，修复后重新上线。正式 worker 已有新任务和数据写入，心跳、API就绪、开机自启、数据库文件属主及无OOM检查通过。首次全量补采仍在队列中，不能把服务已开启写成数据已补齐。

历史完整验收以2026-10-15快照为准，最新实际数据日期看 `/v1/data-overview`；初始恢复目标为2026-10-16，今日收盘后自动转入新交易日。免费公开来源无长期可用性保证，原有未验证ETF窗口、BLS与部分同花顺边界保留，不生成占位数据。
