# A 股 52 周日线契约 · v0.6.1

本次把当前 A 股股票池的日线范围扩为近 **52 个自然周内的实际 CN 交易日**，含不复权 OHLC、成交量及来源有提供的成交额。52 周不固定等于 260 个交易日，也不代表新股和停牌股票必须有同样多的日线。5 日涨幅继续由同次、同源前复权快照的最近 6 个市场收盘计算。

## 查询

- `GET /v1/bars/CN.stock.000001?end=2026-10-15&weeks=52`：不指定 `limit` 返回该窗口所有已落库日线；可用 `limit` 缩小返回数量。响应披露 `window_weeks=52`、实际 `window_sessions`、`window_start`、上市/停牌核对后的 `history_coverage`。
- `GET /v1/history-coverage/CN.stock.000001?end=2026-10-15&weeks=52`：查询相同窗口的完整性及未解释日期。
- 未指定 `weeks` 的旧调用继续限定近 30 个交易日；旧客户端继续工作。请求不会触发采集，也不创建历史扩容队列。
- 仅在生产配置 `stock_history_weeks=52` 时开放该能力。`/v1/data-overview` 和 `/v1/capabilities` 披露该字段；`history_sessions=30` 仍表示原有默认窗口。
- 此参数仅适用于 `CN.stock.*`。ETF、板块、美股、宏观、资金和资讯仍遵循各自已有窗口，不据此宣称已获得一年历史。

API 使用 `0.6.1` 补丁版本。手机/桌面客户端按能力请求 52 周，提供近 30 日、近 90 日和 52 周图表切换；其他标的保持原窗口。新股短序列和有证据的全天停牌不会填造价格，无法解释的缺日会保留在覆盖响应中。

## 采集与验证

```powershell
python scripts/collect_all_a.py --date 2026-10-15 --weeks 52 --plan-only
python scripts/collect_all_a.py --date 2026-10-15 --weeks 52 --workers 4 --budget 7200 --output data/all-a-52w
```

先交叉验证当前四份交易所目录，并准备当日历法、上市日期和可核实的全天停牌证据。脚本以有限时间、数量和并发抓取，可从已完成窗口续接；`--symbols 000001,600000` 可用于小样本。退出 2 表示仍有窗口未解释或未抓完，需要核对，不能当作全量验收通过。

52 周复权快照按股票逐个解码，仅保留最近 6 日供排名使用；可用性接口也只读取快照元数据，避免将全市场一年历史载入 API 内存。日线查询按标的与日期范围使用现有索引。原始适配响应、摘要、上市/停牌依据、数据库备份和 API 返回分别对账。

原有归档保留。本轮是一轮有限手工扩容；自动采集、补采、巡检及自动电脑备份继续关闭。更换服务器需迁移数据库、配置和凭证，Git 不包含生产数据与密钥。
